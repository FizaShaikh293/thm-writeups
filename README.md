I approach each room using a structured penetration-testing mindset:

```text

        ↓
3. Enumeration
        ↓
4. Vulnerability Identification
        ↓
5. Exploitation
        ↓
6. Initial Foothold
        ↓
7. Privilege Escalation
        ↓
8. Flag Capture & Validation
```
